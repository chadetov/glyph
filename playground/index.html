        The compiler runs entirely in your browser (WebAssembly), and it compiles
        the one module in the editor. glyph build compiles your whole
        project, so anything it reads from a sibling .glyph file is
        missing here: the specifier for an import of one of your own modules, and
        the runtime check for a type one of them declares. A module that imports
        only std/* compiles here to what glyph build
        writes for it at your project root, with the std/* specifiers
        pointing into the runtime the build bundles beside its output. This page
        also shows the TypeScript for a module that still has errors, which
        glyph build will not write.
