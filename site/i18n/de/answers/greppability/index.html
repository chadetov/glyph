03 · Navigation per Suche

Kann ein Agent (oder ich) finden, wo etwas definiert ist?

Jedes Konstrukt hat genau eine Form, nach der man sucht. Ein einfaches grep (so navigieren Agenten tatsächlich) landet auf der einen Definition, nicht auf fünfzig Beinahe-Treffern.

Warum das wichtig ist

Ein Agent hat nicht dein ganzes Repo im Kopf; er sucht. Wenn sich ein Konzept auf fünf verschiedene Arten schreiben lässt, übersieht die Suche Fälle, und ein selbstsicherer Agent, der die bestehende Definition nicht findet, erfindet eine zweite. Eine Form pro Konzept heißt, die Suche ist vollständig, also bearbeitet der Agent, was da ist, statt es zu duplizieren.

So sieht es aus

Glyph beschränkt Mutation auf zwei Formen (mut x = … und mut x.method(…)), also beantwortet eine einzige Suche jede Stelle, an der sich Zustand ändert:

grep -rn "mut " src/ (jede Mutation in der Codebasis) 
src/cart.glyph:14:   mut items.push(item)
src/cart.glyph:22:   mut total = total + price
src/user.glyph:8:    mut session.token = fresh

Drei Mutationen, alle davon, in einer Suche. In TypeScript kann sich eine Mutation hinter =, .push(), Object.assign, einem Setter oder einem Spread verstecken. Es gibt kein einzelnes Token zum Greppen, also hat “ändert irgendetwas das hier?” keine verlässliche Antwort. Dieselbe Regel einer einzigen Form macht ganze Kategorien prüfbar:

eine Suche = eine vollständige Antwort 
# every UI component
grep -rn "^component " src/

# every function
grep -rn "^fn " src/

# the entire resource-ownership surface
grep -rn "owned" src/

Es gibt keine Kurzschreibweise für Objektliterale, keinen zweiten Weg, eine Komponente zu deklarieren, keine überladene Syntax, die man auflösen müsste. Weniger Wege, etwas zu schreiben, ist eine echte Einschränkung, und genau darum geht es: Das macht die Suche eines Agenten, und deine, vertrauenswürdig.

Die Konstrukte, die Glyph weglässt, damit man einer Suche vertrauen kann, und warum eine Lint-Regel nicht dieselbe Garantie ist, stehen auf der Seite zur Säule Durchsuchbarkeit.

Wo es steht

Heute verfügbar

Eine kanonische Form pro Konstrukt, Mutation auf zwei durchsuchbare Formen beschränkt (mut), und Prüfungen über ein einziges Schlüsselwort (fn, component, owned, type).

Darauf aufbauend

Der Language Server ergänzt Go-to-Definition und Find-References über den ganzen Workspace: dieselbe Garantie, jetzt interaktiv in deinem Editor.
