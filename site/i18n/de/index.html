Dein KI-Agent schreibt den Code. Der Compiler prüft ihn.

Glyph liest sich wie TypeScript, nur ohne die Hintertüren: kein any, keine Casts, keine ungeprüften Daten, jeder Fall behandelt. Es kompiliert zu lesbarem TypeScript, du behältst also node, npm und deinen bestehenden Code.

$ npx -y @glyphlang/glyph init hello && cd hello && npm install && npx glyph run

Ohne globale Installation. Wer glyph lieber im PATH hat: npm install -g @glyphlang/glyph tsx typescript

Eine Änderung in einer echten Anwendung

examples/apps/csvql ist eine Query-Engine für CSV-Dateien in diesem Repository, mit einer Value-Union im Zentrum. Bevor du einen Fall hinzufügst, frag den Compiler, welche Stellen er erreicht.

glyph_variants { name: "Value" } 
10 match sites across 4 files
 8 will fail compilation
 2 contain a catch-all and will silently absorb it
dann den Fall hinzufügen und glyph check ausführen 
8 errors, E0200 non-exhaustive match. The same eight.
The two catch-all sites report nothing at all.

Die Vorhersage traf bei allen acht zu. Die anderen beiden, exec::total und render::literal_text, kompilieren weiter und schicken den neuen Fall dorthin, wohin ihr Catch-all zeigt. Ein Agent, der die acht Fehler behebt und dann aufhört, hat einen grünen Build und zwei lebende Bugs, und erst die Abfrage benennt sie.
