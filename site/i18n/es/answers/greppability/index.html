03 · Navegar buscando

¿Puede un agente (o yo) encontrar dónde está definido cualquier cosa?

Cada construcción tiene exactamente una forma que buscar. Un grep normal (que es como navegan los agentes) da con la única definición, no con cincuenta casi aciertos.

Por qué importa

Un agente no tiene todo tu repositorio en la cabeza; busca. Una forma por concepto significa que la búsqueda es completa, así que el agente edita lo que hay en lugar de duplicarlo.

Si un concepto se puede escribir de cinco formas distintas, la búsqueda se deja casos, y un agente seguro de sí mismo que no encuentra la definición existente se inventa una segunda.

Detalles por qué la misma pregunta no tiene respuesta en TypeScript

En TypeScript una mutación se puede esconder detrás de =, .push(), Object.assign, un setter o un spread. No hay un único token que buscar con grep, así que “¿algo cambia esto?” no tiene una respuesta fiable.

El compilador mantiene la búsqueda completa

Un método que cambia su array (push, pop, sort, splice y cinco más) solo puede ser la llamada entera de una sentencia mut. En cualquier otro sitio es E0240, también dentro de una expresión, donde una función auxiliar podría ordenar el array de quien la llama mientras lee un elemento:

glyph check 
[E0240] `xs.sort(cmp)` changes `xs` in place, and its value is used here
 4 │   return xs.sort(cmp)[0]
   │ Help: `array.sort(xs, cmp)` returns a sorted copy and leaves `xs` alone

xs.push(4) en una línea propia recibe el mismo código, y glyph fix escribe el mut por ti. La dirección contraria es E0241: mut xs.concat(ys) no cambia nada y descarta el array nuevo, así que la auditoría nunca lista una línea que no escribe nada.

Categorías enteras en una sola búsqueda

La misma regla de una sola forma hace auditables categorías enteras:

una búsqueda = una respuesta completa 
# every UI component
grep -rn "^component " src/

# every function
grep -rn "^fn " src/

# the entire resource-ownership surface
grep -rn "owned" src/

No hay shorthand de objetos literales, ni una segunda forma de declarar un componente, ni sintaxis sobrecargada que desambiguar. Tener menos formas de escribir algo es una restricción, y es justo lo que se busca: es lo que hace que la búsqueda de un agente, y la tuya, sean de fiar.

Las construcciones que Glyph deja fuera para que una búsqueda sea de fiar, y por qué una regla de lint no es la misma garantía, están en la página del pilar de buscabilidad.

Dónde está

Disponible hoy

  • Una forma canónica por construcción.
  • Mutación restringida a dos formas que se pueden buscar con grep (mut), y una escritura sin él, rechazada (E0240), vaya a un array o a un Set, un Store o un Deque de la biblioteca estándar. Un valor de un paquete npm no se juzga en ningún sentido.
  • Auditorías con una sola palabra clave (fn, component, owned, type).

Por encima

  • El servidor de lenguaje añade ir a la definición y buscar referencias en todo el workspace: la misma garantía, ahora interactiva en tu editor.
