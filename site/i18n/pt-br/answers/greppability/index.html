03 · Navegação por busca

Um agente (ou eu) consegue achar onde qualquer coisa está definida?

Cada construção tem exatamente uma forma a ser buscada. Um grep simples (o jeito como agentes navegam de fato) cai na única definição, e não em cinquenta quase acertos.

Por que isso importa

Um agente não guarda o repositório inteiro na cabeça; ele busca. Uma forma por conceito significa que a busca é completa, então o agente edita o que já existe em vez de duplicar.

Se um conceito pode ser escrito de cinco jeitos, a busca deixa casos de fora, e um agente confiante que não acha a definição existente inventa uma segunda.

Detalhes por que a mesma pergunta não tem resposta em TypeScript

Em TypeScript uma mutação pode se esconder atrás de =, .push(), Object.assign, um setter ou um spread. Não existe um token único para dar grep, então “alguma coisa muda isto?” não tem resposta confiável.

O compilador mantém a busca completa

Um método que altera o array (push, pop, sort, splice e mais cinco) só pode aparecer como a chamada inteira de uma instrução mut. Em qualquer outro lugar é E0240, inclusive dentro de uma expressão, onde uma função auxiliar poderia ordenar o array de quem a chamou enquanto lê um elemento:

glyph check 
[E0240] `xs.sort(cmp)` changes `xs` in place, and its value is used here
 4 │   return xs.sort(cmp)[0]
   │ Help: `array.sort(xs, cmp)` returns a sorted copy and leaves `xs` alone

xs.push(4) numa linha sozinho recebe o mesmo código, e o glyph fix escreve o mut para você. A direção oposta é E0241: mut xs.concat(ys) não altera nada e descarta o array novo, então a auditoria nunca lista uma linha que não escreve nada.

Categorias inteiras numa só busca

A mesma regra de uma forma só torna categorias inteiras auditáveis:

uma busca = uma resposta completa 
# every UI component
grep -rn "^component " src/

# every function
grep -rn "^fn " src/

# the entire resource-ownership surface
grep -rn "owned" src/

Não há shorthand de objeto literal, nem um segundo jeito de declarar um componente, nem sintaxe sobrecarregada para desambiguar. Menos jeitos de escrever uma coisa é uma restrição de verdade, e é esse o objetivo: é o que torna confiável a busca de um agente, e a sua.

As construções que o Glyph deixa de fora para que a busca seja confiável, e por que uma regra de lint não é a mesma garantia, estão na página do pilar de buscabilidade.

Situação atual

Disponível hoje

  • Uma forma canônica por construção.
  • Mutação restrita a duas formas que o grep encontra (mut), e uma escrita em array sem ele, recusada (E0240).
  • Auditorias com uma única palavra-chave (fn, component, owned, type).

Por cima disso

  • Escritas por meio de Set, Store e Deque da biblioteca padrão ainda não são verificadas quanto ao mut
    Detalhes

    O verificador do Glyph ainda não tipa esses receptores, então seen.add(x) e mut seen.add(x) são aceitos, e o corpus usa as duas grafias. Tipá-los e marcar os métodos que escrevem é o próximo passo planejado. Um valor de um pacote npm não é julgado em nenhuma direção: mut antes de uma chamada dele é permitido e não é obrigatório.

  • O language server adiciona go-to-definition e find-references em todo o workspace: a mesma garantia, agora interativa no seu editor.
