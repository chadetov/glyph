Um projeto precisa ativar cada uma delas, e um agente pode desativá-la de novo. No Glyph, nenhuma delas é uma opção de configuração.

Uma mudança, em uma aplicação real

examples/apps/csvql é um motor de consultas sobre CSV que fica neste repositório, com uma union Value no centro. Antes de adicionar um caso a ela, pergunte ao compilador quais pontos ela alcança.

glyph_variants { name: "Value" } 
10 match sites across 4 files
 8 will fail compilation
 2 contain a catch-all and will silently absorb it
depois adicione o caso e rode glyph check 
8 errors, E0200 non-exhaustive match. The same eight.
The two catch-all sites report nothing at all.

A previsão acertou os oito. Os outros dois, exec::total e render::literal_text, continuam compilando e mandam o caso novo para onde o catch-all deles apontar. Um agente que corrige os oito erros e para ali fica com o build verde e dois bugs vivos, e é a consulta que aponta quais são.
