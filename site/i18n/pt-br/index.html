Seu agente de IA escreve. O compilador confere.

O Glyph se lê como TypeScript, sem as válvulas de escape: sem any, sem casts, sem dados não verificados, todo caso tratado. Ele compila para TypeScript legível, então você mantém o node, o npm e o código que já tem.

$ npx -y @glyphlang/glyph init hello && cd hello && npm install && npx glyph run

Sem instalação global. Para ter glyph no PATH: npm install -g @glyphlang/glyph tsx typescript

Seu agente pode perguntar ao compilador antes

examples/apps/csvql é um motor de consultas sobre CSV que fica neste repositório, com uma union Value no centro. Antes de adicionar um caso Date a ela, um agente pergunta ao servidor MCP do compilador o que essa edição quebra. A resposta, reduzida aqui a veredito, local e função, aponta dez pontos de match em quatro arquivos.

Cada entrada WILL_FAIL vem com o erro que vai gerar, e adicionar só o caso deu exatamente esses oito erros E0200. Os dois pontos ABSORBS não geram nada: render::literal_text teria impresso um literal de data sem as aspas, e exec::total teria contado cada data como zero. Um agente que trabalha só com os erros do compilador corrige oito pontos e para com o build verde. Perguntado de novo depois da correção, o compilador responde WILL_FAIL nos dez, então o próximo caso também não passa despercebido.
