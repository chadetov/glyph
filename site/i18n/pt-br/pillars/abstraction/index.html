Pilar 03 · O acabamento

Abstração

Diga o que você quer dizer com um núcleo pequeno e ortogonal: pattern matching em vez de escadas de switch, Result em vez de exceções lançadas, records com nomes em vez de tuplas. Um jeito bom por conceito, não as camadas que o TypeScript foi acumulando.

Jeitos demais de dizer a mesma coisa

O TypeScript cresceu por acúmulo e manteve todas as camadas.

  • Casos fixosVocê pode modelar um conjunto fixo de casos como um enum, uma union de literais de string ou um objeto const.
  • FormatosPode descrever um formato com uma interface, um type ou uma class.
  • Todo o restoHá namespaces e módulos, decorators e funções de ordem superior, cinco idiomas para quase tudo, cada um com seus casos de borda.

Para uma pessoa, isso é flexibilidade. Para um agente, é um campo minado: mais jeitos de expressar uma coisa significam mais chances de escolher o que tem a armadilha, e mais idiomas para manter em mente enquanto faz isso.

O pilar de abstração do Glyph é uma subtração deliberada: uma ferramenta afiada por tarefa, escolhida para que o jeito óbvio também seja o seguro.

01 match é a única condicional

Não existe instrução if/else. Ramificar é match, em todo lugar, e match é uma expressão: produz um valor.

Uma construção cobre um teste booleano, um despacho sobre uma union e uma tabela de valores, então não há decisão a tomar sobre qual forma de ramificação usar.

02 Unions etiquetadas e pattern matching

O jeito de modelar "um destes formatos" é uma union etiquetada, e o jeito de desmontá-la é match, que desestrutura o conteúdo no mesmo passo em que escolhe o caso.

feed.glyph 
type Feed =
  | Loading
  | Loaded(Array<Post>)
  | Failed(string)

fn view(feed: Feed) -> string {
  return match feed {
    Loading => "...",
    Loaded(posts) => render(posts),   // posts is Array<Post> here
    Failed(msg) => msg,               // msg is string here
  }
}
Detalhes o que você não escreve mais à mão

Nenhum campo discriminante para manter à mão, nenhuma escada de switch sobre uma tag em string, nenhum cast dentro de cada ramo para recuperar o formato.

03 Result em vez de exceções

Falha é um valor, não um salto escondido no fluxo de controle. Uma função que pode falhar diz isso no tipo de retorno (Result<T, E>), e você compõe falhas com o operador ? em vez de envolver as chamadas em try/catch e torcer para que a coisa certa lance a classe certa.

O caminho de erro fica tão visível quanto o caminho feliz.

04 Records com nomes em vez de tuplas posicionais

Dados são descritos com campos nomeados, sempre. O formato se lê igual na definição, na construção e no uso.

TypeScript: o que são [0] e [1]? point.ts 
function origin(): [number, number] {
  return [0, 0];
}
const p = origin();
p[0]; p[1];  // x? y? row? col?
Glyph: os nomes viajam com o valor point.glyph 
type Point = { x: number, y: number }

fn origin() -> Point {
  return { x: 0, y: 0 }
}
Detalhes sem atalhos, sem tuplas anônimas

Não há atalho de object literal nem tupla anônima cujos [0] e [1] você precisa lembrar.

05 Uma primitiva por tarefa

Quando um conceito precisa de uma ferramenta própria, o Glyph dá exatamente uma.

  • Estado compartilhadoEstado mutável compartilhado fica num std/store.
  • HandlesUm handle de arquivo ou socket que precisa ser fechado uma vez é um recurso owned.
  • IteraçãoIteração é for x in xs.

Cada um é uma primitiva única, com nome e feita para aquilo, não um padrão que você reconstrói a partir de um saco de peças genéricas e erra em algum detalhe.

Abstração aqui significa menos ferramentas, e mais afiadas, não mais ferramentas. Todo conceito tem uma forma óbvia, e a forma óbvia é a que você deve usar.

O benchmark: em breve

O jeito de medir isso é a área de superfície: quantos conceitos distintos um leitor precisa ter em mente para entender um programa, e quanto código é preciso para expressar uma tarefa comum de forma limpa.

Um núcleo menor é mais fácil para uma pessoa aprender uma vez e mais fácil para um modelo acertar toda vez. Essa é a camada de acabamento numa frase: tire as escolhas que só acrescentavam risco, e o que sobra é uma linguagem que diz o que quer dizer.
