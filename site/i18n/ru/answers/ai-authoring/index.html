07 · Исходная посылка

Может ли ИИ надёжно писать на языке, который почти не видел?

В основном да. Glyph читается как TypeScript: те же примитивные и обобщённые типы (string, number, Array<T>), большая часть тех же выражений и пакеты из npm, импортируемые по имени. Но это не подмножество TypeScript: match, Result и fn name(x: T) -> R это синтаксис, которого в TypeScript нет, а if, тернарного оператора и приведений типов в Glyph нет. Большая часть того, что модель уже знает, переносится, а места, где это не так, называет компилятор.

Почему это важно

Это честный вопрос скептика: LLM предсказывает следующий токен по огромному объёму кода на существующих языках, значит, на языке почти без обучающих данных писать должно быть трудно. Ответ в устройстве языка: Glyph не чужой. Он выглядит как TypeScript, поэтому модель уже знает большую его часть; отличий мало, их можно перечислить, и каждое из них падает сразу при компиляции, а не проходит молча.

Посмотрите сами

Агент, который угадал неправильно, не выпускает свою догадку. Он получает точную ошибку, которую можно исправить, и исправляет её в том же цикле:

цикл исправления за один шаг 
// agent writes, reaching for a TypeScript habit:
if user.admin { grant() }

[E0006] Glyph has no `if`
   ╰─ `match` is the only conditional:
      match user.admin { true => grant(), false => void, }

Ошибка называет конструкцию Glyph и показывает её форму, так что до исправления одна правка: не нужно лезть в исходники и гадать. Этот короткий цикл и компенсирует нехватку обучающих данных. Один документ, llms.txt, даёт агенту структуру программы, стандартную библиотеку и каждую диагностику с исправлением, а glyph llms выводит тот же справочник офлайн.

Текущее состояние

Уже работает

Синтаксис в духе TypeScript, ошибки со стабильным кодом, которые называют исправление, и llms.txt / glyph llms как единый справочник для любого агента.

Проверяется

Бенчмарк доли успеха (число попыток до исправления в сравнении с TypeScript на той же задаче), чтобы превратить «справилось» в измеренное число.
