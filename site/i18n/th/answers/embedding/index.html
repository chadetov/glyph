10 · ภายในแอปของคุณ

นำ Glyph มาใช้ในแอปที่มีอยู่ได้ไหม หรือต้องเปลี่ยนทั้งหมด?

ไม่ต้องเขียนใหม่ แอปยังเป็น TypeScript และเขียนส่วนที่พลาดไม่ได้ (model, สิทธิ์, การเปลี่ยนสถานะ, การคำนวณเงิน) ด้วย Glyph glyph build emit module ที่แอปของคุณ import ได้เหมือนไฟล์ในเครื่องทั่วไป ไม่ต้องตั้งค่า bundler และไม่ต้องมี path alias

ทำไมเรื่องนี้สำคัญ

ทีมส่วนใหญ่เขียนแอปใหม่ทั้งหมดไม่ได้ และแอปส่วนใหญ่ก็ไม่จำเป็นต้องใช้ Glyph ส่วนที่จำเป็นคือแกนของโดเมน: กฎที่เอเจนต์ AI จะมาแก้เดือนหน้า และไม่มีใครอยากให้ผิดแบบเงียบๆ การเก็บแกนนั้นไว้ใน Glyph ทำให้คุณได้ match ที่ต้องครบทุกกรณี ไม่มี cast และขอบเขตที่ถูก validate ตรงจุดที่คุ้มค่า ขณะที่ React component, การจัดสไตล์ และ infrastructure ยังเป็น TypeScript ธรรมดา

ดูของจริง

ไดเรกทอรีเดียวของซอร์ส Glyph คอมไพล์เข้าไปในแอป และ UI import ไปใช้:

layout แบบผสม: แกนของโดเมนเป็น Glyph ที่เหลือเป็น TypeScript 
src/
  glyph/          # models.glyph, permissions.glyph, analytics.glyph
  generated/      # glyph build --out src/generated src/glyph
  components/     # hand-written React/TSX

// BoardContext.tsx: the app imports compiled Glyph like a local module
import { TaskCard, can_move } from "../generated/models";

const parsed = TaskCard.parse(payload);  // Result, not an exception

ทุกอย่างที่โค้ดที่ emit ออกมาต้องใช้เดินทางไปพร้อมกับมัน import เป็นแบบ relative รวมถึง standard library ที่ bundle มาด้วย tsconfig.json และ bundler ของโปรเจกต์จึงไม่ต้องเพิ่มอะไร: Vite scaffold แบบมาตรฐานคอมไพล์และ bundle output ได้ตามที่เป็น และไฟล์ชุดเดียวกันผ่าน tsc --strict ของโปรเจกต์หลักด้วย ทำเครื่องหมายสิ่งที่แอป import ด้วย pub declaration ที่ไม่มีมันจะเป็น private ของ module นั้น นี่ไม่ใช่สมมติฐาน: วิศวกรภายนอกสร้าง Kanban board ด้วย React แบบนี้ โดยมี RBAC matrix สูตร analytics และการเปลี่ยนสถานะอยู่ใน module ของ Glyph สี่ตัว ใต้ UI React ที่เขียนเอง

สถานะตอนนี้

ใช้ได้วันนี้

output ที่ emit ออกมาวางลงในโปรเจกต์หลักได้โดยไม่ต้องแก้: ใช้ specifier แบบ relative ตลอด type ของ prelude ติดมากับโค้ดเอง ตรวจแล้วกับ Vite scaffold แบบมาตรฐาน, tsc --strict ของโปรเจกต์หลัก, esbuild และ tsx คู่มือการ deploy อธิบาย layout แบบผสมไว้

กำลังมา

ยังไม่มี watch mode: ต้องรัน glyph build ใหม่หลังแก้ซอร์ส .glyph (ผูกไว้ในสคริปต์ dev) module ที่ใช้ std/fs หรือ std/net ต้องมี @types/node ในโปรเจกต์หลัก เหมือน TypeScript ที่แตะ Node ทั่วไป
