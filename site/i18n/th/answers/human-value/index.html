Glyph คุ้มไหมถ้าฉันไม่ได้ใช้ AI?

คุ้ม การวางกรอบเรื่องเอเจนต์ AI เป็นหัวข้อหลักเพราะเอเจนต์ทำสิ่งเหล่านี้พังอยู่ตลอด แต่การรับประกันทุกข้อที่อยู่เบื้องหลังเป็นประโยชน์ทางวิศวกรรมตรงๆ ที่คนได้รับโดยตรง เจอเรื่องไม่คาดคิดตอนรันน้อยลง diff เล็กลง และโค้ดที่ grep หาได้จริง ไม่มีข้อไหนต้องใช้ LLM

ในหน้านี้

  1. ฟีเจอร์ของภาษา
  2. สิ่งที่คุณได้ แม้ทำงานคนเดียว
  3. ทำไมเปิดด้วยเรื่องเอเจนต์
  4. สถานะตอนนี้

นี่คือฟีเจอร์ของภาษา ไม่ใช่ฟีเจอร์ของ AI

ตัดคำว่า "เอเจนต์" ออกแล้วอ่านรายการ: ไม่มี any, match ที่ครบทุกกรณี, error เป็นค่า, type ที่ถูกตรวจตอนรัน, รูปแบบ declaration เดียวต่อชื่อ, รูปแบบมาตรฐานที่ diff คงที่

ใครที่เคยเขียน Rust, Elm หรือ OCaml จะจำได้ว่านี่คือสิ่งที่ทำให้ codebase ดูแลง่าย มันเป็นความคิดที่ดีมานานก่อนที่ AI จะเขียนโค้ด Glyph แค่นำมาใส่ในภาษาที่หน้าตาแบบ TypeScript ซึ่งนำมาใช้ทีละไฟล์ได้

สิ่งที่คุณได้ แม้ทำงานคนเดียว

  • ถูกปลุกตอนตีสามน้อยลงข้อมูลที่ขอบเขตถูก validate โดยการออกแบบ (User.parse) และ case ที่ขาดไปเป็น compile error ไม่ใช่ undefined ที่โผล่บน production
  • รีวิวเร็วขึ้นการแก้หนึ่งบรรทัดคือ diff หนึ่งบรรทัด คนรีวิวจึงอ่านการเปลี่ยนแปลง ไม่ใช่การจัดรูปแบบที่วุ่นวายรอบๆ
  • หาอะไรก็เจอgrep "fn parseUser" เจอนิยามเลย ไม่มี overload, barrel หรือ decorator ทำให้กระจัดกระจาย
  • รับคนใหม่ได้ง่ายขึ้นcore เล็กๆ ที่มีวิธีเดียวในการทำแต่ละอย่าง หมายถึงความรู้เฉพาะกลุ่มที่คนต่อไปต้องเรียนน้อยลง

แล้วทำไมถึงเปิดด้วยเรื่องเอเจนต์?

เพราะผลตอบแทนตรงนั้นใหญ่กว่า คนจะเรียนรู้ที่จะรัน linter และจัดการ case ในที่สุด ส่วนเอเจนต์หยิบ any มาใช้ ลืม arm แล้ว merge ไปทั้งที่เขียว และไว้ใจไม่ได้ว่าจะเปิดเครื่องมือที่ต้องเลือกเปิดไว้

รายละเอียด พื้นฐานยังอยู่ไม่ว่าทางไหน

คุณค่าของการทำให้ความเข้มงวดไม่ใช่ตัวเลือกทวีขึ้นเมื่อเครื่องเป็นคนเขียนโค้ด แต่พื้นฐาน (ประโยชน์ข้างบน) ก็ยังอยู่ไม่ว่าคุณจะใช้เอเจนต์หรือไม่

ให้มองว่าเป็น TypeScript ที่เข้มกว่า ซึ่งบังเอิญเหมาะกับเอเจนต์มาก ไม่ใช่เครื่องมือสำหรับเอเจนต์ที่จะคุ้มก็ต่อเมื่อคุณใช้เอเจนต์

สถานะตอนนี้

สิ่งที่ต้องแลก

  • ถ้าคุณกำลังเริ่มของใหม่ หรือทีมของคุณให้คุณค่ากับวินัยแบบภาษาตระกูล ML อยู่แล้ว ประโยชน์จะมาทันที
  • ถ้าคุณทำคนเดียวบน TS stack ที่โตเต็มที่และมีเครื่องมือครบ การตัดสินใจจะก้ำกึ่งกว่า: Glyph ยังเป็นพรีวิวช่วงแรก และนั่นเป็นต้นทุนจริงที่ต้องชั่งน้ำหนัก

ไม่ว่าทางไหน

  • ทางออกมีอยู่เสมอ: มันคอมไพล์เป็น TypeScript ที่อ่านได้และเป็นของคุณ การลองกับ module เดียวจึงถูกและย้อนกลับได้
