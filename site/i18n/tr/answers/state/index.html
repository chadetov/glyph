14 · Paylaşılan durum

Değiştirilebilir durumu fonksiyonlar arasında nasıl paylaşırım?

Bir store ile. Glyph'te değiştirilebilir global değişken yoktur. Modül bağlamaları const'tur. Paylaşılan durum bir std/store'da yaşar: get() ile okuduğunuz ve set()/update() ile değiştirdiğiniz bir değeri tutan, modül düzeyinde bir const. Bağlamanın kendisi asla değişmez; yalnızca içindeki değer bir metot çağrısıyla değişir, yani her yazma işlemi grep'leyebileceğiniz düz bir .set( ya da .update( metnidir.

Görün

Store'u modül kapsamında bir kez tanımlayın. Modüldeki her fonksiyon onu paylaşır. main boyunca taşınan bir let yok, değer yakalayan closure'lar yok:

tasks.glyph 
import std/store { create }
import std/array

type Task = {
  id: number,
  title: string,
}

const tasks = create<Array<Task>>([])
const next_id = create(0)

fn add(title: string) -> Task {
  next_id.update(fn(n: number) -> number {
    return n + 1
  })
  let task = { id: next_id.get(), title: title }
  tasks.update(fn(cur: Array<Task>) -> Array<Task> {
    return array.push(cur, task)
  })
  return task
}

fn all() -> Array<Task> {
  return tasks.get()
}

Neden değiştirilebilir bir global değil de bir store

Bu bilinçli bir tasarım tercihi. Glyph, mut'u yerel atamalarla sınırlı ve modül bağlamalarını const tutar, çünkü dağınık bir yazılabilir global kümesi, durumu anlamayı ve bulmayı zorlaştıran şeyin ta kendisidir. Bir store bu kuralların hiçbirinin gevşetilmesini gerektirmez: const s bağlaması değiştirilemez ve içindeki değer yalnızca set/update üzerinden değişir. Böylece paylaşılan durum yeni bir sözdizimi olarak değil, bir kütüphane olarak gelir (linear tipler yok, gevşetilmiş değiştirme kuralları yok) ve değiştirme işlemi programınıza dağılmak yerine denetlenmiş tek bir yerde yaşar.

TypeScript ile ortak bir pürüz: boş bir koleksiyon eleman tipini çıkaramaz, bu yüzden onu açık bir tip argümanıyla başlatın: create<Array<Task>>([]). Skaler bir store (create(0)) tipini sorunsuz çıkarır.

Şu anki durum

Bugün yayında

create, get, set ve update içeren std/store: paylaşılan değiştirilebilir durum için tek ve grep'lenebilir yer.

Yolda olanlar

Aynı temel yapı üzerinde kolaylıklar (türetilmiş/hesaplanmış store'lar, abonelikler), dili değiştirmeden üstüne eklenecek.
