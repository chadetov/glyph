--- version: 0.1.132 month: 2026-11 date: 2026-11-10 tags: breaking ---

This release removes places where a guarantee depended on how something was spelled, and closes more of the programs only tsc used to refuse.

An alias is the type it names, however you import it

pub type Page = Doc was already a second name for Doc. Written through a namespace, pub type Page = a.Doc, it was a different type: Page and a.Doc did not match, Page.parse did not exist, and a misspelled field passed. Both spellings now mean the same thing. A misspelled field through an alias names both types: type `Page` (a second name for `a.Doc`) has no field `titel`; did you mean `title`?

Reading through a Nullable

note.glyph 
pub fn label(n: Nullable<Note>) -> string {
  return n?.name ?? "none"
}

n?.name is now checked against Note's fields. Its value is the name or JavaScript's undefined, and Glyph has no type for undefined, so it can only be the left side of ?? or compared with ==. Anywhere else, such as a let or a "${...}", it is the new E0235. That catches "${n?.name}" printing the text "undefined", which tsc accepts. n.name without the ? is E0235 too.

json.parse validates in both spellings

parse<Doc>(body) through import std/json { parse } used to compile to a cast, where json.parse<Doc> validated. Both validate now, and so does a T that is an Option, a Nullable, a Record of a checked type, or a primitive. Some T still cast, and that is next: a type parameter, an extern_ts type, a package type, a container of unknown, and an Array alias imported from another module.

Smaller checks

A wrong number of type arguments, including none on a generic type (let b: Box), is the new E0233. print takes a string and assert takes a bool, so print(42) is an argument mismatch: write print("${n}"). A match arm for a string outside its union is E0220. xs.length is a number. A record where Record<string, V> is declared is compared field by field. kinds.type works as a type name.

The editor

The emitter's errors no longer disappear while you type; they move with your edits until the next check. Editing one file refreshes the other open files that import it. For agents, glyph/applyEdit now refuses only what an edit introduces, warnings included, and returns what the file already had under preexisting. So ok: true no longer means the file is clean; it means the edit introduced nothing, and the file is clean only when preexisting is empty too. While the file has an error, the warnings and the emitter's checks do not run, so an edit to it can add one of those and still get ok: true (G313). It still checks only the edited file, so glyph check remains the authority for changes that affect other modules.

This release is breaking, at compile time and at run time.

At run time: parse<Doc>("{}") through import std/json { parse } returned Ok in 0.1.131 and returns Err here.

In the editor protocol: glyph/applyEdit answers ok: true for an edit that introduces nothing to a file that already had a diagnostic, where 0.1.131 answered ok: false. On a refusal, diagnostics now holds only what the edit introduced, and the rest is under preexisting. An agent that read ok as "clean" must also check that preexisting is empty.

Under glyph check, these exit 0 in 0.1.131 and 1 here, although tsc accepts them: a match over an alias of an imported union that misses a variant; type T = a.Doc where ...; an @open record or a tagged union where Record<string, string> is declared; let x = n?.name, "${n?.name}" and {n?.name} in JSX on a Nullable (write {n?.name ?? ""}); and the named-import parse<Doc> over a record holding an extern_ts field.

Under --no-tsc only, programs tsc already refused now exit 1: a misspelled field through an alias, a wrong or missing type-argument count, let a: string = xs.length, print of anything but a string and assert of anything but a bool, a literal arm outside its union, and return n?.name from a function returning Nullable<string>. Some programs go the other way and now pass. With tsc agreeing: let p: Page = d with Page = a.Doc, a Box<string> where Record<string, string> is declared, a Box<T> where Record<string, unknown> is declared, and a full match over an alias of http.RedirectPolicy. Under --no-tsc only, and still refused by tsc: a Box<T> whose field is an Array<T> or an optional T where a Record of strings is declared (G314).
