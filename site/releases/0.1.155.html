--- version: 0.1.155 month: 2026-11 date: 2026-11-21 tags: breaking headline: A SQL query's text has to be fixed when the program is written ---

The query you pass to std/sqlite is now a sqlite.Sql, which only accepts text the program wrote: a string literal, a constant, a + of constants, or a let that is never reassigned and holds one of those. A query built from a run-time value is E0239:

[E0239] `db.query` runs its first argument as SQL, and this one is built from `name` at run time, so a value with a quote in it can change the query
Help: Pass the value as a parameter: `db.query("SELECT * FROM users WHERE name = ?", [name])`.

Before this release, db.query("... WHERE name = '${name}'", []) compiled, and so did hoisting the same string into a let first, which is what Glyph's own style advice produces. With x' OR '1'='1 as the name, it returned every row.

The help rewrites the query with ? placeholders only where SQL takes a value: after a comparison, in LIMIT and OFFSET, and inside VALUES (...) or IN (...). Where the interpolation names a table or a column, it says so, because a parameter cannot fill that position. A column picked at run time is written as a match whose arms are constant strings, which counts as constant. Each suggested rewrite was run against a real database: it returns no rows for the injection and the same rows as the constant query otherwise. A two-statement exec is not rewritten into run, which would drop the second statement.

Text that has to vary goes through std/taint: sqlite.from_trusted(taint.sanitize(...)), or taint.trust_unchecked(...) for text you wrote, both names you can search for. A constant imported from another module counts once it is declared pub const BASE: sqlite.Sql = "..." where it is written, under either import spelling.

Breaking

A query built from a run-time value no longer compiles (0.1.154 exits 0, 0.1.155 exits 1). Separately, a taint.Tainted value given where a taint.Trusted one is declared is now refused by Glyph's own checker; full check already refused it through tsc, so only check --no-tsc changes. No tracked .glyph file or example app is affected: the job queue and task apps already pass literals and constants.
