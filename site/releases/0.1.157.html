--- version: 0.1.157 month: 2026-11 date: 2026-11-21 tags: breaking headline: A value with no text form can't be turned into text by accident ---

Putting a record inside ${} used to compile, and printed [object Object]. The same went for an Option, an array, or a function you forgot to call, and for joining any of them to a string with +. Now each of those is E0237:

[E0237] `${user}` turns a `User` into text, and a record has no text form: it prints `[object Object]`
Help: Interpolate a field, such as `${user.id}`.

One rule covers every implicit conversion: each ${}, each operand of a + whose other side is a string, and the argument of string.from. The types that can become text are a short list (string, number, int, bigint, bool, string-literal unions, and aliases of these), and everything else is refused, including any type added to the language later. A + chain is judged as a whole, so "Hello " + name + ", " + u is caught at u.

The help depends on the type. For a record it suggests the first field that can be text. For an Option or a Result it suggests a match. For an array it points to string.join, for a Decimal to to_string(), and for unknown to an is string arm, which works now that 0.1.156 narrows those. Every suggested rewrite is applied in a test and has to pass the full check, tsc included. glyph --explain E0237 has the full table.

string.from still accepts a value declared unknown, because it is the explicit way to render one, such as a failed task's error. A call that was never awaited is left to E0238 from 0.1.154, so it gets one error rather than two. A sqlite.Sql counts as text, so "SELECT " + sql stays a constant query.

std/decimal now has types in the checker: decimal.decimal returns a Result, and a Decimal's methods are typed. As a side effect, a match on one of those methods' results now emits a boolean cast in the generated TypeScript.

Writing this rule turned up a real bug in one of the example apps. The site generator interpolated an issue's path, an array, and printed items,0,name. It joins the path with dots now.

Breaking

A record, Option, array or other value with no text form inside ${}, joined with +, or passed to string.from no longer compiles (0.1.156 exits 0, 0.1.157 exits 1, with or without tsc). No tracked example app is newly refused.
