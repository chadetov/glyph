--- version: 0.1.158 month: 2026-11 date: 2026-11-21 tags: breaking headline: A lambda parameter without an annotation takes its type from where the lambda is passed ---

Before this release, a lambda parameter written without a type was not checked by Glyph at all. In users.map(fn(p) -> string { return p.nmae }), nothing knew p was a User, so the typo passed check --no-tsc, and "${p}" printed [object Object] past the rule 0.1.157 added. Now the parameter takes the type of the slot the lambda is passed into:

[E0210] type `User` has no field `nmae`; did you mean `name`?

A lambda gets its parameter types from a call argument (the callee's parameter, with its type parameters bound from the earlier arguments), an annotated let or const, a return in a function with a declared return type, a field of a typed record literal, or an attribute of a component whose props Glyph knows. The built-in array methods that take a callback (map, forEach, filter, find, reduce, sort and the rest) type it from the array's element type. Hover shows the inferred type, and the E0238 help for a missed await inside forEach or map now names the right fix for each.

A lambda with nothing around it to supply a type, such as let k = fn(p) { ... }, still is not checked, and hover says so. A DOM event handler on a plain element keeps React's type.

Testing this turned up a run-time bug that 0.1.157 shipped. A two-name for i, x in v over a value typed unknown always used the record form, so on an array the index came out as a string and i + 1 printed 01. The loop now decides array or record at run time, and both names are typed unknown for Glyph and for tsc, so using the index as a number or a string needs a check first.

Breaking

A field typo or a record converted to text inside a lambda passed to a typed slot now fails check --no-tsc (0.1.157 exits 0, 0.1.158 exits 1), and under full check when tsc did not already catch it. A loop over an unknown value that used its index as a string or a number fails full check until the index is narrowed. No tracked program or example app is newly refused.
