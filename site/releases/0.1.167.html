--- version: 0.1.167 month: 2026-11 date: 2026-11-23 tags: breaking headline: Writes to a Set, Store or Deque are mut statements, like array writes ---

Since 0.1.160, xs.push(4) has to be written mut xs.push(4), so grep -n "^\s*mut " finds every change to an array. The stdlib Set, Store and Deque were the exception: seen.add(x) and hits.set(n) changed state with no mut line. 0.1.163 gave the checker their types, and 0.1.166 typed values held in an unannotated const. Now their writing members follow the same rule:

[E0240] `seen.add("a")` changes `seen` in place, and a call that changes a value is written as a `mut` statement
Help: write `mut seen.add("a")`, so `grep "^\s*mut "` finds every change to `seen`

The writing members are Set.add and remove, Store.set and update, and the four push_ and pop_ members of Deque. Readers such as has, get, peek_front and len are not, and putting mut in front of one is E0241. Every decimal.Decimal method returns a new value, so mut d.add(e) is E0241 too, with help to write mut d = d.add(e), or to bind a new name when d is a const. sqlite.Db calls change state outside the program and are judged in neither direction.

The help depends on what the value is used for. let had = seen.remove(1) is told to read seen.has(1) first, and a pop_front used as a value is told to read peek_front first. A write to the set or array a Store holds goes through mut st.update(...). glyph fix inserts the mut where the value has nowhere to go, and now also turns let _ = q.pop_front() into mut q.pop_front(), for arrays as well.

Which members write is checked twice. Every method of each type has to be classified, and node calls each one on a fresh instance to confirm the split. A write through an interface that names the method (interface Adder { add: fn(number) -> void, }) is not covered yet; that is G448, and D5 lists it.

Breaking

Yes, under full check as well as --no-tsc: a bare seen.add("a") and a mut d.add(d) on a Decimal exit 0 under 0.1.166 and 1 under 0.1.167. Seven example apps had 43 such writes, migrated in the same change; across 285 tracked programs nothing else differs.
