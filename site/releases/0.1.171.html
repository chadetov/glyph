--- version: 0.1.171 month: 2026-11 date: 2026-11-23 headline: Each type parameter knows the declaration it belongs to ---

Glyph's checker compared type parameters by name alone, so the T of one generic function could be mistaken for the T of another. With type One<T> = { v: T, } and fn wrap<T>(xs: Array<T>) -> One<T>, a function returning wrap([]) where Record<string, string> is declared was refused with "found One<?>", and inside a generic function whose own parameter was also called T the callee's T was read as the caller's. tsc accepts both.

Now every type parameter carries the declaration that owns it: the function, component, type or interface that declares it, a stdlib function for the stdlib's rows, and the union for Option and Result. Parameters are compared by owner and name. The answer is the same whether the callee is local, imported by name, reached through a namespace or held in a const. With 0.1.170's alias expansion, the same holds through a second name, and one more false refusal goes: Record<string, Same<T>> where a field of type T is returned.

This release adds no refusals. Across 285 tracked programs the output is byte-identical to 0.1.169 and 0.1.170. The next release uses the owner to decide a function's own type parameter.

Not breaking

Every change removes a refusal that tsc does not make.
