--- version: 0.1.174 month: 2026-11 date: 2026-11-24 tags: breaking headline: A block's last expression is checked against the declared return ---

A function's last expression is its return value, but Glyph only compared values written after return with the declared type. fn z() -> string { 5 } passed check --no-tsc, and so did a lambda whose tail disagreed with its declared return. Only tsc caught it.

A returned tail now goes through the same check as a return: the comparison with the declared type, the context a declared return gives a lambda, and the handling of pending values. Which tails count as returned is one rule shared by the checker and the emitter. A named function's tail is returned when it declares a type other than void, a component's always is, and a lambda's is unless the lambda is written -> void.

Match arms are checked one by one

Where a type is declared, a match is now compared arm by arm, including nested matches and the last expression of a block arm. Before, the arms were joined into one type that nothing compared, so return match b { true => 5, false => "x" } under -> string passed. The error now points at the arm that is wrong and names that arm's type.

A never helper

fn fail() -> never { process.exit(1) } used to be refused with expected never, found ? once it was written with return, and comparing tails would have spread that to the usual way of writing it. A value the checker has no type for is no longer refused where never is declared. A 5 there is still an error. Giving process.exit a real never type is G480.

Some(5) and None returned where T is declared still pass --no-tsc, at a tail and at return alike. A body that ends with no value under a declared return is not checked yet either.

Breaking

Yes. fn z() -> string { 5 } exits 0 under 0.1.172's check --no-tsc and 1 under 0.1.174. One program goes the other way: pub fn a() -> never { return process.exit(1) } exits 1 under 0.1.172 and 0 now, and tsc accepts it. Across 384 tracked programs the only difference from 0.1.172 is 0.1.173's circular-bound test.
