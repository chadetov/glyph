--- version: 0.1.179 month: 2026-11 date: 2026-11-24 tags: breaking headline: A value written by mut is checked against the place it goes into ---

Glyph compared the value of let x: number = ... with its annotation, but a later mut x = "s" was never compared with anything. The same held for a field write, an array element write and a map write: mut r.n = "x", mut v[0] = 5 on an Array<string> and mut m["k"] = 5 on a Record<string, string> all passed check --no-tsc, and only tsc caught them.

Now mut P = e checks e against P's type exactly the way an annotated let checks its initializer, as E0204. A name holds its annotation, or the type of its initializer when it has none, so let y = 1 followed by mut y = "s" is refused too. A field holds its declared type, an array element its element type, and a map value its value type. A match is checked arm by arm. The note says where the place's type came from, for example `y` holds a `number`: the type of its initializer at line 9, and a `mut` does not change a binding's type.

A name whose type comes from somewhere else, such as a for binding, a match payload or a lambda parameter typed by its position, is not judged yet, and neither is a receiver the checker cannot type.

A let over a const

Checking writes showed that let dir = DEFAULT_DIR, over an unannotated const DEFAULT_DIR = "examples/apps/chat", held the exact literal type, where TypeScript widens it to string. Without a fix, five of the example apps would have been refused for writing a different directory into dir. Such a let now holds a string, locally or through an import. An annotated const keeps its type.

The key of an index expression is still not checked against the key type: mut m["exec"] = 2 on a Record<Mode, number> passes. That is G511, scheduled for the next batch.

Breaking

Yes. let x: number = 1 followed by mut x = "s" exits 0 under 0.1.178's check --no-tsc and 1 under 0.1.179. Because of the const widening, passing such a let where a string-literal union is declared is now E0211, as tsc already reported it. Every new refusal is one tsc makes, apart from an element write inside an is Array arm, where tsc sees an any[]. Across the 375 programs the corpus script measures, the output is identical to 0.1.178.
