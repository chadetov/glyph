Answers

The questions engineers actually ask.

Straight, specific answers. Each one names the strength, shows a real example, and states the current edge honestly. Start wherever your doubt is. New to Glyph? The 10-minute Start Here is the fastest first run.

The problem it solves#

What an agent's edit can break without anyone noticing, and what Glyph does about each.

01What stops an agent from silently breaking my code?

No any, no casts, exhaustive match, runtime-checked types, and colocated tests that run on every build.

 02Will agent edits stay clean, or reformat my whole file?

A one-line change is a one-line diff. One canonical layout, nothing repacked.

 03Can an agent (or I) find where anything is defined?

One name, one declaration form. grep always lands on it.

Deciding whether to adopt it#

Why a language rather than more tooling, and what taking it on costs.

04Why TypeScript, and not Go or a new language?

Because that's where your ecosystem is, and it's why adoption is per-file.

 05Why not just strict TypeScript + zod + eslint + ts-pattern?

Non-optionality: the language the agent can't config-disable.

 06Is Glyph worth it if I'm not using AI?

Yes: the guarantees are plain engineering wins a human gets directly.

 07Can an AI reliably write a language it's barely seen?

Most of what a model knows about TypeScript carries over, and the compiler names the places it doesn't.

 08Will a new Glyph release break my build?

Projects pin the compiler exactly, so no release arrives by accident. glyph doctor says one exists; glyph upgrade takes it.

Using it with your stack#

npm packages, an existing app, API boundaries, React.

09Can I use my existing TypeScript, JavaScript, and npm libraries?

Yes: import any npm package, keep a hand-written .ts shim where you need one, and import Glyph back into .ts.

 10Can I adopt Glyph inside my existing app, or is it all-or-nothing?

No rewrite: the domain core in Glyph, the rest in TypeScript. The output drops into a stock Vite scaffold with zero config.

 11Do I have to hand-write a validator for every API?

No. Declare a type, get a validated boundary for free.

 12Can I generate a typed client and server from my API spec?

glyph gen openapi/zod/dts: committed, greppable code.

 13Does it work with React: components, hooks, and Context?

First-class JSX, hooks, and exhaustive reducer actions.

 14How do I share mutable state between functions?

A store: a const whose .set/.update are the write-surface.

What you can build with it#

The language and standard library, by the kind of program.

15Is this a real language, or a toy with gaps?

Module visibility, interface bounds, defer, a match that works as any value and carries its type, and a standard library that has slice, pad_start, and fold.

 16Can I trust it with money, and with input I don't control?

Exact decimals and ids, invariants as types, injection as a compile error.

 17Can I serve a web page, or only a JSON API?

HTML, redirects, response headers, and form posts, without a hand-written server.

 18Can I write a program someone types into?

io.read_line answers a line as it arrives instead of waiting for stdin to close, so a REPL or a game loop works.

 19Can I write a server, or does the process just exit?

main sets up and returns; the process stays alive while sockets and timers are pending, the same rule Node uses.

 20Can I handle binary data, or is everything a string?

std/bytes is a sequence of octets, with codecs that refuse malformed input instead of skipping it, and HMACs that take a real key.

Working with an agent#

Questions an agent asks the compiler before and after an edit.

21Can the compiler tell me what a change will break before I make it?

glyph_impact: one verdict per site, from a closed list, with the reason, before you touch the file.

 22Can my agent ask the compiler what a symbol is before it writes code?

glyph_symbol: a union's variants with the syntax that constructs each, in one call. Eleven tools, each with a glyph query verb.

 23When the build fails, does the compiler tell my agent how to fix it?

The diagnostic carries the symbol at fault, the legal alternatives, and what a repairing edit must not break. glyph fix writes the ones the compiler settles on its own.

 24Is the documentation my agent reads generated, or written by hand and out of date?

glyph llms --json emits the diagnostics, the prelude, the stdlib signatures and the tool manual out of the compiler's own tables, and a gate fails when a hand-written copy disagrees.

Errors, editors and production#

What you see when something is wrong, from the editor to on-call.

25What's the editor, debugging, and error experience?

LSP + VS Code extension, and Elm-quality errors with stable codes.

 26Why does Glyph catch what tsc catches, but earlier?

await context, a match arm with no value, and a missing mut, reported against your source instead of the emitted TypeScript.

 27When a parse fails, do I find out why?

Which field, which rule it broke, the where predicate it violated, and a code to branch on.

 28When it breaks in production at 3am, what does on-call see?

Readable TS you own, source maps back to your .glyph, and a run that reports what build reports.
