An error nobody looked at

Likely 4 of 5Severity 4 of 5

Calling something that can fail and moving on.

TypeScriptcompiles with no warning
ts.ts
save(user); // returns { ok: false }
return "done";
$ tsx ts.ts
done

The failure is dropped and the user is told it worked.

Nothing catches itnot even with every compiler flag and typescript-eslint strict on

GlyphwarnedE0217
glyph.glyph
save(user)
return "done"
$ glyph build
[E0217] Warning: typecheck: this `Result` is discarded; its `Err` case is silently ignored
Help: Handle it with `match`, propagate it with `?`, or bind it (`let _ = ...`) to say the discard is intentional.

Glyph points at the dropped failure.

A warning, not an error. To drop it on purpose, say so: let _ = save(user).
