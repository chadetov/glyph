Eine Methode, die ihr Objekt vergisst

Wahrscheinlichkeit 2 von 5Schwere 3 von 5

Eine Methode als Wert herumreichen.

TypeScriptkompiliert, stürzt dann zur Laufzeit ab
ts.ts
const up = name.toUpperCase;
console.log(up());
$ tsx ts.ts
TypeError: String.prototype.toUpperCase called on null or undefined

Die Methode wird von ihrem String abgelöst und verliert ihn aus dem Blick.

Nur Lintgefunden durch die Lint-Regel unbound-method

Glyphbeim Build abgelehntE0234
glyph.glyph
let up = name.toUpperCase
$ glyph build
[E0234] Error: typecheck: method `toUpperCase` of `string` is read without being called

Eine Methode muss dort aufgerufen werden, wo sie gelesen wird. Übergib stattdessen eine Funktion.

Eine TypeScript-Methode hängt von dem Objekt ab, auf dem sie aufgerufen wird (this). Als Wert aus name.toUpperCase() herausgelöst, weiß sie nicht mehr, welchen String sie verwenden soll.
