Dein KI-Agent schreibt den Code. Der Compiler prüft ihn.

Glyph liest sich wie TypeScript, nur ohne die Hintertüren: kein any, keine Casts, keine ungeprüften Daten, jeder Fall behandelt. Es kompiliert zu lesbarem TypeScript, du behältst also node, npm und deinen bestehenden Code.

$ npx -y @glyphlang/glyph init hello && cd hello && npm install && npx glyph run

Ohne globale Installation. Wer glyph lieber im PATH hat: npm install -g @glyphlang/glyph tsx typescript

21 von 37

Jedes TypeScript-Beispiel in der Liste besteht tsc --strict ohne Fehler. Jedes wird außerdem gegen ein maximal konfiguriertes Projekt geprüft: alle Compiler-Flags, die strenger als --strict sind, dazu typescript-eslint strictTypeChecked. Von den 37 Fällen erkennt dieses Setup 21 überhaupt nicht. Ein standardmäßig deaktiviertes Compiler-Flag findet 5, eine Lint-Regel 11. Ein Projekt muss jedes davon einschalten, und ein Agent kann es wieder ausschalten. In Glyph ist keins davon eine Konfigurationsoption. Insgesamt gibt es 47 geprüfte Fälle: 37 TypeScript-Fälle, 5 JavaScript-Fallen, die es in Glyph nicht gibt, und 5 Lücken, die Glyph noch nicht schließt. Glyph lehnt 28 davon beim Build ab (23 TypeScript-Fälle und 5 Fallen).

Dein Agent kann zuerst den Compiler fragen

examples/apps/csvql ist eine Query-Engine für CSV-Dateien in diesem Repository, mit einer Value-Union im Zentrum. Bevor ein Agent einen Fall Date hinzufügt, fragt er den MCP-Server des Compilers, was diese Änderung kaputt macht. Die Antwort, hier gekürzt auf Urteil, Stelle und Funktion, nennt zehn match-Stellen in vier Dateien.

Jeder WILL_FAIL-Eintrag nennt den Fehler, den er auslösen wird, und nur den Fall hinzuzufügen ergab genau diese acht E0200-Fehler. Die beiden ABSORBS-Stellen melden nichts: render::literal_text hätte ein Datumsliteral ohne Anführungszeichen ausgegeben, und exec::total hätte jedes Datum als null gezählt. Ein Agent, der nur mit Compilerfehlern arbeitet, behebt acht Stellen und hört mit einem grünen Build auf. Nach der Korrektur erneut gefragt, antwortet der Compiler an allen zehn Stellen WILL_FAIL, also rutscht auch der nächste Fall nicht durch.

Glyph findet noch nicht alles. 5 bekannte Lücken haben eine Reproduktion und eine Gap-Nummer, und Logikfehler kommen in Glyph genauso durch wie in TypeScript. Was es noch nicht findet →
