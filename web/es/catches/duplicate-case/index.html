Un caso duplicado

Probabilidad 2 de 5Gravedad 3 de 5

Decidir qué pedidos se pueden reembolsar.

TypeScriptcompila sin ningún aviso
ts.ts
case "paid": return true;
case "shipped": return true;
case "paid": return false; // never runs
$ tsx ts.ts
true

La segunda regla está muerta. Nadie se da cuenta.

Solo lintlo detecta la regla de lint no-duplicate-case

Glyphrechazado al compilarE0305
glyph.glyph
"paid" => true,
"shipped" => true,
"paid" => false,
$ glyph build
[E0305] Error: emit: this match arm can never run: an earlier arm already matches `"paid"`
Help: Remove the later arm, or give the two arms different patterns (a nested variant, a literal, or an object pattern) so they test different values.

Un brazo que nunca se puede ejecutar es un error.

tsc no marca una etiqueta case que aparece dos veces.
