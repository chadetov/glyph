# Glyph pages as Markdown

> Markdown copies of the glyphlang.io pages agents read most, generated from the same source as the HTML on every build. The language reference for agents is https://glyphlang.io/llms.txt.

## Getting started

- [For agents and tool builders](https://glyphlang.io/agents/index.md): How an agent works with Glyph: an MCP server with eleven tools, the same queries on the command line, and glyph check --agent for repairing a red build.
- [Evidence · how each claim on this site is checked](https://glyphlang.io/evidence/index.md): How each claim on this site is checked: the catches fixtures and the CI gate behind them, the TypeScript setup they are compared with, and how to reproduce one.
- [Coming from TypeScript · what changes in Glyph](https://glyphlang.io/from-typescript/index.md): Glyph reads almost like TypeScript and compiles to it. What changes: a few syntax deltas, no any, as or !, one greppable escape hatch, and how npm works.
- [Start Here · your first Glyph program in 10 minutes](https://glyphlang.io/start/index.md): Scaffold a Glyph project with npx, run it, break it on purpose, read the compiler error and fix it. Ten minutes, nothing installed globally.
- [For teams · what Glyph guarantees and costs](https://glyphlang.io/teams/index.md): For a lead weighing Glyph: what the compiler guarantees and where it stops, adopting it in a TypeScript app, the exit story, version pinning and pre-1.0 status.

## Answers

- [Can an AI write a language it has barely seen?](https://glyphlang.io/answers/ai-authoring/index.md): Glyph reads like TypeScript but is not a subset of it. Most of what a model knows about TypeScript carries over, and the compiler names the places it does not.
- [Can my agent ask the compiler about a symbol first?](https://glyphlang.io/answers/ask-the-compiler/index.md): glyph_symbol answers in one call: a union's variants, a record's fields, a function's signature, and whether a match over it must be exhaustive.
- [Can I handle binary data, or is everything a string?](https://glyphlang.io/answers/binary/index.md): std/bytes gives Glyph an immutable byte sequence, with hex, base64 and base32 codecs that refuse malformed input, plus file I/O and HMACs over bytes.
- [Can I generate a typed client from my API spec?](https://glyphlang.io/answers/codegen/index.md): Yes. glyph gen openapi turns a spec into a typed HTTP client or into server stubs with a router, and gen zod works from zod schemas. The output is plain Glyph.
- [What does on-call see when it breaks at 3am?](https://glyphlang.io/answers/debugging/index.md): Glyph compiles to readable TypeScript with a v3 source map back to each .glyph file, so stack traces and tsc errors point at the Glyph you wrote.
- [Will agent edits stay clean, or reformat my file?](https://glyphlang.io/answers/diff-stability/index.md): Glyph has one canonical layout and requires trailing commas, so a one-line change is a one-line diff. Agents can't bury a real change under reformatting noise.
- [Why does Glyph catch what tsc catches, but earlier?](https://glyphlang.io/answers/early-errors/index.md): Glyph reports await outside an async fn, a match arm that produces no value and a missing mut against your source, with the rule and the fix, before tsc.
- [Can I adopt Glyph inside my existing app?](https://glyphlang.io/answers/embedding/index.md): No rewrite: keep the app in TypeScript, write the domain core in Glyph, and import the compiled modules like any local file. It works under stock Vite.
- [Can I trust it with money and untrusted input?](https://glyphlang.io/answers/finance/index.md): Money is exact (decimals and integers past 2^53), invariants are types the boundary enforces, and untrusted input cannot reach a SQL or shell sink unsanitized.
- [Is the documentation my agent reads generated?](https://glyphlang.io/answers/generated-docs/index.md): glyph llms --json emits the diagnostics, the prelude, the stdlib signatures and the language decisions from the compiler's own tables, so they cannot drift.
- [Can an agent (or I) find where anything is defined?](https://glyphlang.io/answers/greppability/index.md): Every construct in Glyph has one shape to search for, so grep (or an agent's search) lands on the one definition, not fifty near-misses.
- [Is Glyph worth it if I'm not using AI?](https://glyphlang.io/answers/human-value/index.md): Yes. AI agents are the headline, but every guarantee (exhaustive match, no any, runtime-checked types, greppable code, stable diffs) helps people too.
- [Can the compiler tell me what a change will break?](https://glyphlang.io/answers/impact/index.md): glyph_impact takes the declaration you are about to change and the edit, and answers with a verdict and a reason for every site, before you touch the file.
- [Can I use my TypeScript, JavaScript and npm code?](https://glyphlang.io/answers/imports/index.md): Glyph compiles to ordinary TypeScript and rides npm: a .glyph module imports any package and is importable from your existing .ts. Adopt it one file at a time.
- [Answers · what engineers ask about Glyph](https://glyphlang.io/answers/index.md): Specific answers to what engineers ask about Glyph: what stops silent breakage, React and npm, why not tooled TypeScript, and debugging in production.
- [Can I write a program someone types into?](https://glyphlang.io/answers/interactive-cli/index.md): io.read_line returns as soon as a line arrives instead of waiting for stdin to close, so a REPL, a game loop or a chat client answers while you type.
- [Is this a real language, or a toy with gaps?](https://glyphlang.io/answers/language/index.md): Module visibility, structural interfaces for generic bounds, defer, structured concurrency and match as a value, and the JavaScript semantics it inherits.
- [Can I write a server, or does the process just exit?](https://glyphlang.io/answers/long-running/index.md): A Glyph program can be a long-running server. main sets up and returns; the process stays alive while sockets and timers are pending, exactly as Node does.
- [When a parse fails, do I find out why?](https://glyphlang.io/answers/parse-errors/index.md): A failing parse names the field, says which rule the value broke, quotes the where predicate it violated, and tags the issue with a code you can branch on.
- [Does it work with React, hooks and Context?](https://glyphlang.io/answers/react/index.md): React is built in: a component compiles to a function component, JSX lowers to createElement, and a reducer's actions are matched exhaustively.
- [Does the compiler tell my agent how to fix it?](https://glyphlang.io/answers/repair-protocol/index.md): Each diagnostic carries the types, the symbol at fault and the legal alternatives, and glyph fix writes the repairs the compiler can settle on its own.
- [How do I share mutable state between functions?](https://glyphlang.io/answers/state/index.md): Glyph has no mutable globals. Shared state lives in a std/store: a module-level const whose get, set and update are the only writes, found in one search.
- [What's the editor, debugging, and error experience?](https://glyphlang.io/answers/tooling/index.md): A language server for any editor, a VS Code extension, error messages with stable codes and glyph --explain. You debug the readable TypeScript it emits.
- [Do I have to hand-write a validator for every API?](https://glyphlang.io/answers/typed-apis/index.md): No. In Glyph a type is its own runtime validator, so request and response bodies are checked with no validator to write, and the types can come from an OpenAPI spec or a .d.ts.
- [Will a new Glyph release break my build?](https://glyphlang.io/answers/upgrades/index.md): A Glyph project pins its compiler exactly, so a release never reaches you by accident. glyph doctor tells you one exists and glyph upgrade moves you to it.
- [What stops an agent from silently breaking my code?](https://glyphlang.io/answers/verifiability/index.md): Changes that compile and then break in TypeScript, like a missing case, an unhandled error or a renamed field, are compile errors in Glyph the agent must fix.
- [Why not tooled TypeScript: tsc, zod, eslint?](https://glyphlang.io/answers/vs-tooled-ts/index.md): Tooled TypeScript gets far, but each guarantee is opt-in and an agent can route around it. In Glyph the strictness is the language, not a config file.
- [Can I serve a web page, or only a JSON API?](https://glyphlang.io/answers/web-serving/index.md): std/http serves HTML pages, redirects, custom response headers and form posts, not only JSON, with the response headers modeled by the type checker.
- [Why TypeScript, and not Go or a new language?](https://glyphlang.io/answers/why-typescript/index.md): TypeScript is where agents already write the most code and where npm, React, and Node live. Glyph is adoptable one file at a time only because its target is TS.
