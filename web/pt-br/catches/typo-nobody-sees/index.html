16

Um erro de digitação que ninguém vê

Probabilidade 4 de 5Gravidade 3 de 5

Ler um campo de uma resposta.

TypeScriptcompila e depois falha em tempo de execução
ts.ts
const data = await res.json();
return data.usr.name;
$ tsx ts.ts
TypeError: Cannot read properties of undefined (reading 'name')

res.json() é any, então nada nele é verificado.

Só lintdetectado pela regra de lint no-unsafe-member-access

Glyphrecusado no buildrecusado pelo glyph checkTS18046
glyph.glyph
return match json.parse(text) {
  Ok(data) => data.usr.name,
  Err(_) => "unreadable",
}
$ glyph build
[TS18046] Error: tsc: 'data' is of type 'unknown'.
Help: TypeScript's checker rejected the code this expression compiles to. The caret is on the Glyph expression that produced it.

Não existe any. Dados que ninguém verificou são unknown; json.parse<User> dá um tipo a eles.

any desliga a verificação de tipos em tudo que toca, e se espalha: data.usr também é any. O Glyph não tem any. A recusa aqui vem da etapa do tsc que glyph check e glyph build rodam; o checker do próprio Glyph ainda não vê isso (G381).
