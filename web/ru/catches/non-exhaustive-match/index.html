Необработанный вариант

Вероятность 5 из 5Тяжесть 4 из 5

Агент добавляет статус "archived". Обработчик, который сообщает о каждом статусе, был написан до его появления.

TypeScriptкомпилируется без предупреждений
ts.ts
switch (s) {
  case "todo":
    console.log("not started");
    break;
  case "doing":
    console.log("in progress");
    break;
  case "done":
    console.log("finished");
    break;
}
$ tsx ts.ts
finished
archived logged nothing

Архивирование ничего не пишет в лог. Ничто не говорит, что switch устарел.

Только линтерловит правило линтера switch-exhaustiveness-check

Glyphотклонено при сборкеE0200
glyph.glyph
match s {
  "todo" => print("not started"),
  "doing" => print("in progress"),
  "done" => print("finished"),
}
$ glyph build
[E0200] Error: typecheck: non-exhaustive match on `"todo" | "doing" | "done" | "archived"`: missing variants "archived"
Help: Add an arm for each missing variant.

Сборка останавливается и называет вариант.

TypeScript проверяет, что switch покрывает все варианты, только если функция возвращает значение из каждой ветки, или с идиомой assertNever. Обработчик, который ничего не возвращает, не получает ни того, ни другого. В Glyph каждый match обязан покрыть все варианты, поэтому добавление нового варианта перечисляет все места, которые нужно изменить.
