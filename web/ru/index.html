Код пишет ваш ИИ-агент. Проверяет компилятор.

Glyph читается как TypeScript, но без лазеек: нет any, нет приведений типов, нет непроверенных данных, каждый случай обработан. Он компилируется в читаемый TypeScript, так что node, npm и ваш код остаются с вами.

$ npm install -g @glyphlang/glyph

Случаи, которые в TypeScript не ловит ничто

Три случая с самым высоким рейтингом среди тех, что проходят tsc --strict со всеми дополнительными флагами и typescript-eslint в режиме strict. Рейтинг учитывает, как часто агент их пишет и насколько они опасны в продакшене. Примеры показаны на английском, в том виде, в каком они лежат в репозитории.

1

Data from outside the program

A request body, a file, an API response.

TypeScript: compiles, then runs on bad dataGlyph: checked when the data arrives

 2

An error the signature hides

A function that can fail, called by code that does not know it can.

TypeScript: compiles, then crashes at run timeGlyph: refused when you build

 3

An error nobody looked at

Calling something that can fail and moving on.

TypeScript: compiles with no warningGlyph: warned

21 из 37

Все примеры на TypeScript из списка проходят tsc --strict без ошибок. Каждый из них дополнительно проверяется на проекте с максимально строгой настройкой: все флаги компилятора строже --strict плюс typescript-eslint strictTypeChecked. Из 37 случаев такая настройка не ловит 21. Флаг компилятора, выключенный по умолчанию, ловит 5, правило линтера ловит 11. Каждый из них проект должен включить сам, и агент может снова его выключить. В Glyph ни одна из этих проверок не является настройкой.

Одно изменение в реальном приложении

В этом репозитории лежит examples/apps/csvql, движок запросов к CSV. В его центре union-тип Value. Прежде чем добавить в него новый вариант, спросите компилятор, какие места это затронет.

glyph_variants { name: "Value" } 
10 match sites across 4 files
 8 will fail compilation
 2 contain a catch-all and will silently absorb it
затем добавьте вариант и запустите glyph check 
8 errors, E0200 non-exhaustive match. The same eight.
The two catch-all sites report nothing at all.

Прогноз совпал во всех восьми местах. Остальные два, exec::total и render::literal_text, продолжают компилироваться и отправляют новый вариант туда, куда указывает их catch-all. Агент, который исправит восемь ошибок и остановится, получит зелёную сборку и два живых бага, а указывает на них запрос.

Glyph пока ловит не всё. Известных дыр, у каждой из которых есть воспроизведение и номер gap: 11. Логические ошибки проходят в Glyph так же, как в TypeScript. Что он пока не ловит →
