  • ทำไมต้อง Glyph

    เหมาะกับใคร

    • สำหรับคนสร้างเอเจนต์เซิร์ฟเวอร์ MCP และคิวรีที่ตอบได้

    การออกแบบ

    • การออกแบบหลักสี่ข้อ และสิ่งที่ตั้งใจตัดออกไป

    • Glyph เทียบกับ TypeScript ที่ใส่เครื่องมือครบสิ่งที่ tsc แบบ strict, zod และ eslint ยังปล่อยผ่าน
  • เรียนรู้

    • llms.txt สำหรับเอเจนต์ทั้งภาษาในไฟล์เดียวที่เอเจนต์อ่านได้

อ่านเป็นภาษาอังกฤษ

ภาษา: ไทย·อ่านเป็นภาษาอังกฤษ

หน้านี้เป็นฉบับแปล ฉบับภาษาอังกฤษคือฉบับอ้างอิง แจ้งปัญหาเกี่ยวกับคำแปล

กรณีของ TypeScript ทั้งหมด/กรณีที่ 28 จาก 37

28

median ที่ใช้ index เป็นเศษส่วน

โอกาสเกิด 3 จาก 5ความรุนแรง 3 จาก 5

หาค่ากลางของ list ที่เรียงแล้ว

TypeScriptคอมไพล์ผ่าน แล้วให้คำตอบผิด
ts.ts
return sorted[sorted.length / 2];
$ tsx ts.ts
NaN

การอ่าน index 1.5 ได้ undefined และการคำนวณของผู้เรียกเปลี่ยนมันเป็น NaN

ไม่มีอะไรจับได้แม้จะเปิด compiler flag ทุกตัวและใช้ typescript-eslint แบบ strict แล้วก็ตาม

Glyphถูกหยุดตอนรัน
glyph.glyph
return sorted[sorted.length / 2]
$ glyph run
RangeError: index 1.5 is out of range for an array of length 3

index ที่ผิดจะหยุดโปรแกรม แทนที่จะปล่อยให้ NaN ลามต่อ

Glyph ตรวจ index ของ array ทุกครั้งตอนโค้ดรัน กรณีนี้จับไม่ได้ตอน build
