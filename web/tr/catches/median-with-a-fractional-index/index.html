28

Kesirli indeksli bir medyan

Olasılık 5 üzerinden 3Ciddiyet 5 üzerinden 3

Sıralı bir listenin ortasını almak.

TypeScriptderlenir, sonra yanlış sonuç verir
ts.ts
return sorted[sorted.length / 2];
$ tsx ts.ts
NaN

1.5 indeksini okumak undefined verir, çağıranın aritmetiği de bunu NaN'a çevirir.

Hiçbir şey yakalamıyortüm derleyici flag'leri ve strict modda typescript-eslint açıkken bile

Glyphçalışırken durdurulur
glyph.glyph
return sorted[sorted.length / 2]
$ glyph run
RangeError: index 1.5 is out of range for an array of length 3

Hatalı bir indeks programı durdurur, NaN yaymak yerine.

Glyph her dizi indeksini kod çalışırken kontrol eder. Bu durum build sırasında yakalanmaz.
