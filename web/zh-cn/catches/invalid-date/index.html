无效日期

可能性 4/5严重程度 3/5

从表单解析日期。

TypeScript能编译，但得到错误的日期或者崩溃
ts.ts
return new Date(input).toISOString().slice(0, 10);
$ tsx ts.ts
2025-03-02
RangeError: Invalid time value

无效日期会顺延成真实的日期。

没有任何工具能发现即使打开所有编译器 flag 并启用严格模式的 typescript-eslint 也不行

Glyph根本写不出来
glyph.glyph
return match time.parse_iso(input) {
  Some(ms) => "ok ${ms}",
  None => "rejected: ${input}",
}
$ glyph run
rejected: 2025-02-30
rejected: next friday

解析可能失败，类型会说明这一点。

JavaScript 的 Date 会把 2 月 30 日一声不吭地变成 3 月 2 日。Glyph 没有 Date；time.parse_iso 返回 None。
